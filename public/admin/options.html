Answer lists

The answers offered when a question has a fixed set of them. A form asking for a sector or a state fills its options from here, and so does a member's own profile.

Onboarding forms

Each list ships with a default and this workspace can replace it — no deploy, no waiting. Changing a list changes what is offered from now on; answers already collected are untouched, so removing an option never rewrites the applications that chose it.
